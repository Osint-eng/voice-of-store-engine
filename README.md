## ⚠️ Important: Full Source Files

The complete source files (`app.js` ~58 KB, `data.js` ~46 KB, full `index.html` ~30 KB) could not be pushed through the available GitHub API tool due to content size limits in this environment.

**To get the complete working project:**

1. Download the original `voice-of-store-engine.zip` from the chat where this repo was created.
2. Or clone this repo and replace the placeholder files with the ones from the zip:

```bash
git clone https://github.com/Osint-eng/voice-of-store-engine.git
cd voice-of-store-engine
# place the original zip here, then:
unzip voice-of-store-engine.zip
python server.py
```

Then open http://localhost:8080
